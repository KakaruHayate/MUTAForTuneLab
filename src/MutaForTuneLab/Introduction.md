# MUTA for TuneLab

Sing with MUTA voice banks in TuneLab.

- Independent implementation. No MUTA binary or voice data is bundled; the plugin reads
  the voices you already have installed.
- Ships the worldline vocoder, so it works without extra setup.
- Adjustable part, note and automation parameters.

Documentation and releases: <https://github.com/KakaruHayate/MUTAForTuneLab>
